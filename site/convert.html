Drop the game zip + neogeo.zip and this tab converts them. Neither the rom nor the result ever leaves it.

Merged sets: drop the game + parent zips together (e.g. kof98h.zip + kof98.zip + neogeo.zip)

Only MAME Neo Geo romset zips are supported. A romset that does not match MAME's names and chip CRCs will not convert.
