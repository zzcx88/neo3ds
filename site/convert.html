    What you need, what you get
    
    
    A converter that turns MAME romsets you own into 3DS install files. Roms and the BIOS are not provided here.
    

    
    Files a conversion needs
    
    
      
      
    • A game romset zip A zip whose name is still the MAME romset name (for example mslug3.zip). Renaming it means the romset cannot be found.
      • 
      
    • neogeo.zip (the BIOS) Needed for every conversion. Drop it with the game zip and leave the name alone.
      • 
      
    • Files you already own Both have to be yours. This site does not let you download roms or a BIOS.
      • 
    
    

    
    Two kinds of output
    
    
    
      
    
        
    Game CIA (.cia)
    
        
    One file per game. Install it with FBI and the game gets its own icon on the HOME menu.
    
        Per-game CIA install steps
      
    
      
    
        
    Launcher file (.neo3ds)
    
        
    Many games inside one launcher app. The files go in /neo3ds/games/ on the SD card and you pick from the list.
    
        Launcher install steps
      
    
    
    
    
    The two are built separately. For the same game, the CIA copy and the launcher copy share key config, backup RAM and quick saves.
    

    
    Why a zip is stopped before converting
    
    
    Dropping a game zip checks the romset and its chips before anything converts. With several games, each row in the list shows its own reason and only that game is skipped.
    
    
    
      
    
        
    Reason shownWhat to do
    
        
          
    The zip name is not a romset nameLeave the original zip name as it was. If it is kof98h.zip, drop kof98h.zip.
    
          
    A chip CRC differs from the expected versionThat is a different romset version. Drop the original MAME romset zip instead.
    
          
    ROM files are missing, or the parent romset is neededDrop every zip of the same version. For a merged set, add the parent zip too (kof98h.zip + kof98.zip).
    
          
    neogeo.zip (the BIOS) is missingDrop neogeo.zip together with the game zip. Every conversion needs it.
    
          
    neogeo.zip lacks a required chipUse a different neogeo.zip. A file missing chips cannot be converted with.
    
          
    A cartridge the converter does not supportThe romset has a protection chip, needs a trackball, or is bootleg. Pick a convertible game from the compatibility list.
    
          
    The zip could not be readCheck that the zip is not damaged and drop it again.
    
            
      
    
    
    
    
    A failure after the conversion starts is a different thing. It is usually the browser running out of memory or a conversion tool stopping, and the progress log shows the step. Do not swap the game: close other tabs or reload and try again, and if it keeps happening send a problem report with the log.
    

    
    Where your files go
    
    
    The game zips, neogeo.zip and the files you build are processed inside the browser tab and are not sent to a server. No account is needed. The site measures page views, conversion start, done, failure and download clicks, and report submissions; privacy has the details.
