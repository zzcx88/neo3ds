Privacy

The web converter never sends your rom or its file name to a server. This is the complete list of what the site measures and what a report sends.

What is measured

Visit statistics come from Umami Cloud. It counts the following without cookies.

  • Page views: the page URL, the referring page, browser and operating system, device type, and country. The IP address is not stored; only the country is derived from it.
  • Conversion events: the output mode (the game-count range when several zips are queued), the game's romset name (only when it is in the public catalog, otherwise unknown), the stage and reason a run failed (load/bios pairs step and cause), the output mode of a download click, and one event per report submission (no properties).

Not sent: rom files, zip file names, custom icon or banner images, or the converted file. All of them stay inside the browser tab.

Problem reports

Pressing send in the intro page's report form sends the values below to an anonymous Cloudflare Worker, which opens an issue in the public GitHub repository. No account is needed.

  • Sent: the report type, your description and optional game name, the last 200 lines of the converter log, the failed games' public romset names, reasons and stages, the error message, the converter version, the output mode, the page address, and browser information (user agent). Conversion-failure reports also carry the BIOS layout (whether neogeo.zip was dropped or unreadable, AES/MVS chip names and regions, and whether sfix/lo matched).
  • The issue is public and anyone can read it; closing it does not delete it. No identity or email is collected, and no reply is promised.
  • Abuse limit: instead of the IP itself the worker keeps a hash of IP and hour for at most one hour, to allow 5 reports per hour.
  • A report never carries zip file names, rom files (including the BIOS), icon or banner images.

Cookies and ad blockers

No cookies are used, so there is no consent banner. Umami tells visits apart without cookies.

If an ad blocker removes the statistics script, that visit is missing from the counts and nothing else changes: conversion still works.

Processor and retention

Umami Cloud (EU region) processes these events. The site uses its Hobby plan, and raw events are deleted after 6 months. Long-term trends are exported before that.

The numbers are used only to improve the site: which page people read, where conversion fails, and which games are popular. No advertising, selling or profiling.
