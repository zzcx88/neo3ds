Changelog

Offline converter · launcher · engine

  1. v1.5.0 Latest 2026-11-06
    • Get games over Wi-Fi in the launcher: Press Y in the launcher and scan the QR code from the offline converter to get .neo3ds files without taking out the SD card. One QR holds up to six files; with two or more, the launcher shows their names, sizes and the free space first. The web converter cannot send, but the offline converter can send files made on the web. (#254 #261)
    • Send to 3DS window in the converter: The offline converter sends CIAs to FBI and .neo3ds files to the launcher by QR code. Pick files from this session or drop others, and send 2 to 6 of one kind in one QR code. The window can stay open while you keep converting. (#235 #255 #257 #264 #306)
    • Game pictures in the launcher list: The top screen shows a saved picture of the game under the cursor. (#224)
    • Spin Master graphics glitches fixed: Fixed misplaced graphics while scrolling and white rectangles when hit. In a game that rewrites its sprites near the end of a frame, the lines above were drawn with new tiles at the old positions. Installing the new launcher is enough. (#318)
    GitHub release
  2. v1.4.1 2026-10-31
    • MVS: Metal Slug 2 and Last Blade 2 stuck on the green screen: Started on the arcade (MVS) BIOS, these games seemed to freeze on the green check screen for about a minute. In games where the BIOS runs some game code before the check, 1.4.0's fast start ended too early and each frame of the check screen took close to a second to draw. They now start within 2-3 s (measured in Azahar). Installing the new launcher is enough. (#215)
    GitHub release
  3. v1.4.0 2026-10-31
    • Faster start on the MVS BIOS: The arcade (MVS) BIOS checks the board before the game (the green screen); that part now runs fast without drawing. Measured in Azahar it went from about 6 s to about 1 s, and games with more graphics gain more. The check itself still runs, so games behave the same. Installing the new launcher is enough. (#209)
    GitHub release
  4. v1.3.2 2026-10-29
    • macOS: run it where you unzipped it: The app converts even when you launch it from where you unzipped it. Up to v1.3.1 Gatekeeper ran it from a read-only copy and every build failed with "Read-only file system : .../bannertool"; the README also covers moving the app to ~/Applications. (#177)
    • Linux: runnable after unzip: The Linux zip ships makerom and bannertool as executable (0755), so conversion works as soon as you unzip. (#179)
    GitHub release
  5. v1.3.1 2026-10-27
    • macOS app signing: The macOS converter was blocked as damaged by Gatekeeper; it is now ad-hoc signed and opens. (#164)
    GitHub release
  6. v1.3.0 2026-10-26
    • Launcher favorites: Press SELECT or tap the * at the left of a game; All and Fav plus the last tab are remembered. (#135)
    • Windowed converter on Linux and macOS: Build CIAs, launcher files and the launcher CIA in a window, as on Windows; the command line stays.
    • Faster conversion: Graphics are compressed in 16KB blocks, so conversion is faster and files are a little smaller. (#123)
    • Raster effects: Neo Turf Masters water and grass, plus Neo Drift Out stage-start edges and curve backgrounds, are fixed. (#131)
    GitHub release
  7. v1.2.1 2026-10-22
    • Korean and Japanese icons: Offline converter icons and banners no longer show □ for Korean or Japanese titles; the web converter was not affected. (#86)
    GitHub release
  8. v1.2.0 2026-10-21
    • Fullscreen: Screen > Full stretches the top screen, saved per game.
    • Bottom screen off: ⏻ at the top right of the bottom screen turns the backlight off; touch anywhere to turn it back on.
    • Faster drawing: Banded rendering split across two cores cuts frame drops in fullscreen and heavy scenes.
    • Linux and macOS command-line converter: Linux x64 and macOS (Apple Silicon) command-line builds join Windows.
    GitHub release
  9. v1.1.0 2026-10-18
    • Launcher: Install one CIA and drop .neo3ds files in /neo3ds/games/ to pick games in one app. (#11)
    • Quick saves: Three slots per game, via the bottom-screen [Slot] [Save] [Load] (tap twice) or SELECT+L / SELECT+R. (#10)
    • Service menu and backup RAM: Opens the MVS BIOS service menu and saves board settings and high scores to the SD card. (#9)
    • Region and batch conversion: Pick Europe-Asia (default), Japan or USA, and convert several zips in a row. (#8, #12)
    • Sound fixes: Metal Slug 1 BGM slowdown and Sonic Wings 2/3 music stopping are fixed. (#7, #6)
    GitHub release
  10. v1.0.8 2026-10-12
    • Heavy scenes: A slightly late frame no longer costs a whole frame, so Metal Slug 3's heavy machine gun and explosions drop far less.
    • Sound CPU and timing: Idle time of the sound driver is skipped in Metal Slug 2/X/3, and register changes play at their place within the frame.
    GitHub release
  11. v1.0.7 2026-10-11
    • Bottom screen GUI: Touch buttons for Key config, Turbo, System, Diagnostics and Restart, plus title, fps and the key layout; redrawn only on change.

  12. v1.0.6 2026-10-11

  13. v1.0.5 2026-10-11

    • Compatibility: Samurai Shodown V Special verified on hardware; KOF2003, Metal Slug 5 and Garou reported at 60 fps.

  14. v1.0.4 2026-10-11

  15. v1.0.3 2026-10-11

    • Includes the KOF2002 fix: The 1.0.2 KOF2002 crash fix is included.

  17. v1.0.1 2026-10-11

Web converter updates

  1. A clearer converter guide 2026-11-18

    The prerequisites, outputs and pre-conversion blocking reasons now use more space on wide screens, with shorter guide headings and reporting text. (#395)

  2. Large full-set downloads 2026-11-17

    Even with all 159 games converted, downloading them together failed at the browser's 2 GB Blob limit. Results now stay on disk (OPFS) and the ZIP is streamed, so the ~7.4 GB full romset comes down as one file or as 1 GB parts. Files over 4 GB are written as ZIP64. (#388)

  3. What you need, and blocked reasons 2026-11-14

    The converter page now has a static guide: the game romset zip and neogeo.zip (the BIOS) you need, the difference between a game CIA (.cia) and a launcher file (.neo3ds), the seven reasons a game is blocked before conversion with the next step for each, and how that differs from a failure during conversion. It also says how to send a report with the log attached. (#375)

  4. Clearer converter wording 2026-11-12

    Removed sentences that said the same thing two or three times, reworded negative-first copy, and fixed descriptions that did not match what the converter does. Icon and banner labels now read "icon/banner" throughout and log separators are consistent. (#349 #352 #354)

  5. Failure messages and batch results 2026-11-11
    • Plain-language failure alerts and game rows: When a conversion fails, the alert and the game row now show one sentence about the cause and one about what to do. The technical message stays unchanged in the log and in the report payload. (#337)
    • Failure reasons split into memory, tool and game DB: A graphics-stage failure that used to read "the exact cause could not be found" is now reported as one of three things: the browser ran out of memory, a conversion tool stopped, or the game DB failed. The log and report carry the same split. (#342)
    • Missing chips and parent romset are named: When a romset is incomplete, the message names up to four missing chips and says to add the parent romset when one is needed. If the chips are present but their CRCs differ, it says the romset is a different version. (#343)
    • Batch results sort completed games first: When a batch finishes, the list now reorders completed games, then failures, waiting games and unsupported games, and scrolls back to the top. Within each group the original zip order is kept. (#344)
    • The packing step no longer looks frozen: The last packing step used to leave the progress display silent for 2-4 s, which looked like a freeze. It now shows elapsed time, and the finished CIA arrives as a Blob, which also removes a hitch when the result lands. (#345)
  6. Damaged and oversized zips refused 2026-11-10

    Before unpacking, a zip with more than 4096 entries, a single entry over 64 MB, or more than 512 MB of data is refused instead of converted. A forged size header can no longer push the heap. Preflight shows it as "the zip could not be read". (#330)

  7. Result and download flow 2026-11-02
    • Report button removed from the result: The report button next to the download button is gone. After a failure, the alert in the progress section and the report guidance further down still remain. (#240)
    • Launcher CIA install moved to the download page: The converter now makes two things, a game CIA and a launcher file (.neo3ds); installing and updating the launcher CIA is explained on the download page. An old launcher-mode link redirects there. (#242)
    • Small converter layout cleanups: The "no launcher yet?" link in pack mode moved above the Convert button, and the empty drop panel no longer repeats its prompt twice. (#244 #246)
  8. BIOS choice in the log 2026-10-30

    The log now states which BIOS (AES/MVS) and system each game converts with, before the work starts, so the choice is visible even when reading the game data fails. (#208)

  9. Phone layout and batch notices 2026-10-28
    • Batch conversion and the neogeo.zip requirement: A "before you convert" box above the drop area now says that neogeo.zip (the BIOS) is required for every conversion, that several games can be dropped at once, and that only MAME romset zips convert. A failed batch summarises up to three reasons. (#173)
    • On phones the page title comes first: On phone widths the title used to be pushed below the drop panel; it now comes first, so the page says what it does before the form. (#174)
  10. Faster, smaller conversions 2026-10-26

    Sprites are now compressed in 16 KB blocks, which makes conversion faster and the output a little smaller: 64 MB of KOF '98 sprites went from 22.2 MB to 20.3 MB. Existing CIAs made with 4 KB blocks keep working. (#123)

  11. Progress UI and parallel logs 2026-10-25
    • English is the default page, Korean lives at /ko/: The root pages are now English and the Korean edition sits at /ko/. A hint on the English page points Korean readers to it. (#141)
    • The finished flow now lives in one progress section: Download and download-all now sit in a result block inside the progress section, so you can download without scrolling. The reason a game cannot convert shows next to the button, and a failure raises an alert. (#143)
    • Cleaner CIA file names: Game CIA files dropped the -web suffix (kof98h.cia). Switching games resets the progress values. (#145)
    • Parallel logs show game, stage and elapsed time: Each log line now carries the elapsed time, the game and its [n/4] stage, so a parallel batch shows at a glance which game is at which stage. (#152)
    • Progress and list touch-ups: Removed per-stage progress values that meant nothing with parallel workers, and capped the game list at three visible rows. Download-all moved below the Convert button, and Cancel took on a neutral grey tone. (#134 #139 #147 #150)
  12. Much faster conversion 2026-10-24
    • Half the conversion time: sprite compression: A web worker runs on one core, and level-19 compression was the bottleneck. Dropping to level 12 cut a kof98h conversion from 13.9 s to 7.0 s while the output grew by only 0.9%. (#120)
    • Rom zip analysis: 1.8 s to 0.03 s: The converter reads only the zip's central directory to learn names, CRCs and sizes, then unpacks entries when they are needed. A 40.8 MB zip now reads 0.13 MB up front. (#121)
    • Batch conversion in parallel: 3 games 13.7 s to 5.5 s: Each game gets a worker and a finished worker takes the next game. Devices with little memory are held to a single worker. (#122)
    • Mobile memory gate and batch failure handling: An 8 GB Android device that reports deviceMemory now keeps the parallel workers; only an unknown memory size falls back to one. Batch failure paths were unified so a failure is reported once. (#128)
  13. Several roms at once 2026-10-22
    • Many roms at once, listed before conversion: Drop several game zips and the converter lists what it recognised before starting; if one game fails, the rest keep converting. (#74)
    • Pick an icon and banner per game: Choose the picture used as each game's icon (48×48) and banner (256×128), and change it per game from the batch list. (#75 #76)
    • Progress bars for recognition and the whole run: Loading bars now show the recognition step and the whole run, the page moves focus to the progress section, and a download-all button collects every result at the end. (#81)
    • MAME-only notice and preflight blocking reasons: The converter states that only MAME Neo Geo romset zips convert, and shows why a game is blocked before conversion, in Korean and English. (#79)
  14. The web converter opens 2026-10-21
    • The web converter opens: The web converter opened: drop a rom zip and neogeo.zip and the browser builds a 3DS CIA. It covers six protection schemes, game CIAs, launcher files, the launcher CIA and batch conversion, and no file leaves the tab. (#39 #40)
    • Output mode cards: Game CIA, launcher file (.neo3ds) and launcher CIA became separate cards with their output format on each. Progress and log wording follow the chosen mode. (#45)
    • Launcher update notice: The converter notes that updating means installing just the new launcher CIA, and that existing .neo3ds files keep running on it. (#61)
    • Header button converts instead of downloading: The button in the converter page header used to download the offline converter zip. It now reads "Convert now" and starts a conversion on the page you are already on; the offline downloads live on the intro and download pages. (#41)
