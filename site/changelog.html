  1. v1.5.0 Latest 2026-11-06
    • Get games over Wi-Fi in the launcher
      • Press Y in the launcher and scan the offline converter QR to receive .neo3ds files without removing the SD card

      • Files made on the web can be sent with the offline converter
      • The web converter cannot send (#254 #261)
    • Send to 3DS window in the converter
      • Offline converter sends CIAs to FBI and .neo3ds files to the launcher by QR
      • Pick files from this session or drop others
      • 2 to 6 of one kind in a single QR code
      • Window can stay open while converting continues (#235 #255 #257 #264 #306)
    • Game pictures in the launcher list
      • Top screen shows the saved picture of the game under the cursor (#224)
    • Spin Master graphics glitches fixed
      • Scrolling graphics misaligned and white rectangles on hit fixed
      • Games that rewrite sprites near the end of a frame drew the lines above with new tiles at old positions
      • Launcher reinstall only (#318)

Web converter updates

  1. A clearer converter guide 2026-11-18
    • Prerequisites, outputs and pre-conversion blocking reasons use more space on wide screens
    • Shorter guide headings and reporting text (#395)
  2. Large full-set downloads 2026-11-17
    • Full download of all 159 games failed at the browser 2 GB Blob limit
    • Results stay on disk (OPFS) and the ZIP is streamed: the ~7.4 GB full romset arrives as one file or in 1 GB parts
    • ZIPs over 4 GB written as ZIP64 (#388)
  3. What you need, and blocked reasons 2026-11-14
    • Static guide added to the converter page
    • Covers the game romset zip and neogeo.zip (the BIOS), and how a game CIA (.cia) differs from a launcher file (.neo3ds)
    • Table of the seven pre-conversion blocking reasons with the next step for each, kept apart from failures during conversion
    • How to send a report with the log attached (#375)
  4. Clearer converter wording 2026-11-12
    • Sentences that repeated the same guidance two or three times removed
    • Negative-first copy reworded
    • Descriptions that did not match the converter fixed
    • Icon and banner labels read "icon/banner" throughout; log separators consistent (#349 #352 #354)
  5. Failure messages and batch results 2026-11-11
    • Plain-language failure alerts and game rows
      • On failure, the alert and game row show one sentence on the cause and one on what to do
      • Technical message stays as written in the log and the report payload (#337)
    • Failure reasons split into memory, tool and game DB
      • Graphics-stage failures no longer read "the exact cause could not be found": they name browser memory exhaustion, a stopped conversion tool or a game DB failure
      • Log and report carry the same split (#342)
    • Missing chips and parent romset are named
      • Incomplete romset: up to four missing chips named
      • Says to add the parent romset when one is needed
      • Chips present but CRCs different: reported as a different version (#343)
    • Batch results sort completed games first
      • Finished batch reorders the list as completed, failures, waiting and unsupported, then scrolls to the top
      • Original zip order kept within each group (#344)
    • The packing step no longer looks frozen
      • Last packing step no longer leaves the progress display silent for 2-4 s
      • Elapsed time shown, and the finished CIA handed over as a Blob, removing a hitch when the result lands (#345)
  6. Damaged and oversized zips refused 2026-11-10
    • Before unpacking, a zip with over 4096 entries, a single entry over 64 MB or over 512 MB of data is refused instead of converted
    • Forged size headers can no longer push the heap
    • Preflight shows it as "the zip could not be read" (#330)
  7. Result and download flow 2026-11-02
    • Report button removed from the result
      • Report button next to the download button removed
      • On failure, the alert in the progress section and the report guidance below remain (#240)
    • Launcher CIA install moved to the download page
      • The converter makes two outputs: a game CIA and a launcher file (.neo3ds)
      • Installing and updating the launcher CIA is covered on the download page
      • Old launcher-mode links redirect there (#242)
    • Small converter layout cleanups
      • Pack-mode "no launcher yet?" link moved above the Convert button
      • Empty drop panel no longer repeats its prompt twice (#244 #246)
  8. BIOS choice in the log 2026-10-30
    • The log states the BIOS (AES/MVS) and system each game converts with before work starts
    • Choice stays visible even when reading the game data fails (#208)
  9. Phone layout and batch notices 2026-10-28
    • Batch conversion and the neogeo.zip requirement
      • "Before you convert" box above the drop area
      • Says neogeo.zip (the BIOS) is required for every conversion, that several games can be dropped at once, and that only MAME romset zips convert
      • A failed batch summarises up to three reasons (#173)
    • On phones the page title comes first
      • On phone widths the title no longer drops below the drop panel: the page says what it does first (#174)
  10. Faster, smaller conversions 2026-10-26
    • Sprites compressed in 16 KB blocks: faster conversion, slightly smaller output
    • 64 MB of KOF '98 sprites went from 22.2 MB to 20.3 MB
    • Existing CIAs made with 4 KB blocks keep working (#123)
  11. Progress UI and parallel logs 2026-10-25
    • English is the default page, Korean lives at /ko/
      • Root pages now English; the Korean edition at /ko/
      • A hint on the English page points Korean readers to it (#141)
    • The finished flow now lives in one progress section
      • Download and download-all moved into a result block inside the progress section, so no scrolling is needed
      • The reason a game cannot convert shows next to the button
      • A failure raises an alert (#143)
    • Cleaner CIA file names
      • Game CIA files dropped the -web suffix (kof98h.cia)
      • Switching games resets the progress values (#145)
    • Parallel logs show game, stage and elapsed time
      • Every log line carries elapsed time, the game and its [n/4] stage, so a parallel batch shows which game is at which stage (#152)
    • Progress and list touch-ups
      • Per-stage progress values removed from the parallel workers
      • Game list capped at three visible rows
      • Download-all moved below the Convert button
      • Cancel took on a neutral grey tone (#134 #139 #147 #150)
  12. Much faster conversion 2026-10-24
    • Half the conversion time: sprite compression
      • A web worker runs on one core and level-19 compression was the bottleneck
      • Level 12 cut a kof98h conversion from 13.9 s to 7.0 s while the output grew by only 0.9% (#120)
    • Rom zip analysis: 1.8 s to 0.03 s
      • Reads only the zip central directory to learn names, CRCs and sizes, then unpacks entries when needed
      • A 40.8 MB zip now reads 0.13 MB up front (#121)
    • Batch conversion in parallel: 3 games 13.7 s to 5.5 s
      • Each game gets a worker, and a finished worker takes the next game
      • Devices with little memory held to a single worker (#122)
    • Mobile memory gate and batch failure handling
      • An 8 GB Android device that reports deviceMemory keeps the parallel workers; only an unknown memory size falls back to one
      • Batch failure paths unified so a failure is reported once (#128)
  13. Several roms at once 2026-10-22
    • Many roms at once, listed before conversion

      • Changeable per game from the batch list (#75 #76)
    • Progress bars for recognition and the whole run
      • Loading bars show the recognition step and the whole run; focus moves to the progress section so no scrolling is needed
      • A download-all button collects every result at the end (#81)
    • MAME-only notice and preflight blocking reasons
      • States that only MAME Neo Geo romset zips convert
      • Blocking reasons shown before conversion in Korean and English (#79)
  14. The web converter opens 2026-10-21
    • The web converter opens
      • The web converter opened: drop a rom zip and neogeo.zip and the browser builds a 3DS CIA
      • Covers six protection schemes, game CIAs, launcher files, the launcher CIA and batch conversion
      • No file leaves the tab (#39 #40)
    • Output mode cards
      • Game CIA, launcher file (.neo3ds) and launcher CIA became separate cards with their output format on each
      • Progress and log wording follow the chosen mode (#45)
    • Launcher update notice
      • Updating means installing just the new launcher CIA
