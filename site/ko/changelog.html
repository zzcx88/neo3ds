웹 변환기 업데이트

  1. 변환 안내 배치 정리 2026-11-18
    • 준비물·결과물·변환 전 차단 이유를 넓은 화면에서 더 넓게 표시
    • 안내 제목·제보 문구 간결화 (#395)
  2. 대용량 전체 다운로드 지원 2026-11-17
    • 게임 159개 전체 변환 후 전체 다운로드가 브라우저 Blob 2GB 한도에서 실패
    • 결과 파일을 디스크(OPFS)에 두고 ZIP 스트리밍 → 약 7.4GB 전체 롬셋을 한 파일 또는 1GB 분할로 수신
    • 4GB가 넘는 ZIP은 ZIP64로 기록 (#388)
  3. 변환 전 준비물·차단 이유 안내 2026-11-14
    • 변환기 페이지에 정적 안내 추가
    • 게임 롬셋 zip·neogeo.zip(바이오스) 필요, 게임 CIA(.cia)와 런처용 파일(.neo3ds)의 차이 안내
    • 변환 전 차단 이유 7가지와 각각의 다음 행동을 표로 정리, 변환 중 실패와 구분
    • 로그를 첨부해 제보하는 방법 안내 (#375)
  4. 변환 페이지 문구 정리 2026-11-12
    • 같은 안내를 두세 번 반복하던 문장 정리
    • 부정문을 먼저 내세우던 문장 재작성
    • 실제 동작과 다른 설명 수정
    • 아이콘·배너 표기를 '아이콘/배너'로 통일, 로그 구분자 정리 (#349 #352 #354)
  5. 실패 안내와 배치 결과 정리 2026-11-11
    • 실패 알림과 목록을 쉬운 말로
      • 변환 실패 시 알림·게임 줄에 원인 1문장·다음 행동 1문장만 표시
      • 기술적 원문은 로그와 제보 내용에 그대로 유지 (#337)
    • 실패 사유를 메모리·도구·게임 DB로 구분
      • '확실한 원인을 찾지 못했어요'로 묶던 그래픽 단계 실패를 브라우저 메모리 부족·변환 도구 중단·게임 DB 문제로 분리 안내
      • 로그·제보에도 같은 구분 유지 (#342)
    • 빠진 롬 파일과 부모 롬셋 안내
      • 롬셋이 빠졌을 때 없는 칩을 최대 4개까지 이름으로 표시
      • 부모 롬셋이 필요하면 함께 올리도록 안내
      • 칩은 있는데 CRC가 다르면 다른 버전이라고 안내 (#343)
    • 배치 결과를 완료 우선으로 정렬
      • 배치 종료 시 목록을 완료 → 실패 → 대기 → 변환 불가 순으로 재배치, 맨 위로 스크롤
      • 그룹 안 순서는 올린 zip 순서 유지 (#344)
    • 결과물 묶기 단계가 멈춘 것처럼 보이던 문제
      • 마지막 결과물 묶기 단계에서 진행 표시가 2~4초 멈춰 보이던 문제 수정
      • 경과 시간 표시, 완성된 CIA를 Blob으로 바로 전달 → 도착 순간 끊김 감소 (#345)
  6. 손상·대용량 zip 거부 2026-11-10
