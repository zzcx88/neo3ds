웹 변환기 업데이트

  1. 변환 안내 배치 정리 2026-11-18

    준비물과 결과물, 변환 전 차단 이유를 넓은 화면에서 더 넓게 표시하고 안내 제목과 제보 문구를 간결하게 정리했습니다. (#395)

  2. 대용량 전체 다운로드 지원 2026-11-17

    게임 159개를 모두 변환해도 전체 다운로드가 브라우저의 Blob 2GB 한도에서 실패했습니다. 결과 파일을 디스크(OPFS)에 두고 ZIP을 흐르는 대로 만들어, 약 7.4GB 전체 롬셋을 한 파일이나 1GB 분할로 받을 수 있습니다. 4GB가 넘는 ZIP은 ZIP64로 기록합니다. (#388)

  3. 변환 전 준비물·차단 이유 안내 2026-11-14

    변환기 페이지에 정적 안내를 더했습니다. 게임 롬셋 zip과 neogeo.zip(바이오스)이 필요하다는 점, 게임 CIA(.cia)와 런처용 파일(.neo3ds)의 차이, 변환 전에 막히는 이유 7가지와 각각의 다음 행동, 변환 중 실패와의 구분을 표로 정리했습니다. 로그를 첨부해 제보하는 방법도 함께 안내합니다. (#375)

  4. 변환 페이지 문구 정리 2026-11-12

    같은 안내를 두세 번 반복하던 문장, 부정문을 먼저 내세우던 문장, 실제 동작과 다른 설명을 고쳤습니다. 아이콘·배너 표기를 '아이콘/배너'로 통일하고 로그 구분자도 정리했습니다. (#349 #352 #354)

  5. 실패 안내와 배치 결과 정리 2026-11-11
    • 실패 알림과 목록을 쉬운 말로: 변환에 실패하면 알림과 게임 줄에 원인 1문장과 다음 행동 1문장만 보여 줍니다. 기술적인 원문은 로그와 제보 내용에 그대로 남습니다. (#337)
    • 실패 사유를 메모리·도구·게임 DB로 구분: '확실한 원인을 찾지 못했어요'로 뭉뚱그리던 그래픽 단계 실패를 브라우저 메모리 부족, 변환 도구 중단, 게임 DB 문제로 나눠 안내하고, 로그와 제보에도 같은 구분을 남깁니다. (#342)
    • 빠진 롬 파일과 부모 롬셋 안내: 롬셋이 빠졌을 때 어떤 칩이 없는지 최대 4개까지 이름으로 보여 주고, 부모 롬셋이 필요하면 함께 올리라고 안내합니다. 칩은 있는데 CRC가 다르면 다른 버전이라고 알려 줍니다. (#343)
    • 배치 결과를 완료 우선으로 정렬: 배치 변환이 끝나면 목록을 완료, 실패, 대기, 변환 불가 순으로 다시 배치하고 목록을 맨 위로 돌립니다. 그룹 안의 순서는 올린 zip 순서 그대로입니다. (#344)
    • 결과물 묶기 단계가 멈춘 것처럼 보이던 문제: 마지막 결과물 묶기 단계에서 진행 표시가 2~4초 멈춰 보였습니다. 이제 경과 시간을 표시하고, 완성된 CIA를 Blob으로 바로 넘겨 도착 순간의 끊김도 줄였습니다. (#345)
  6. 손상·대용량 zip 거부 2026-11-10

    zip을 풀기 전에 항목 수 4096개, 항목 하나 64MB, 전체 512MB를 넘으면 변환하지 않고 거부합니다. 위조된 크기 헤더로 메모리를 밀어내는 zip도 막습니다. 변환 전 확인 단계에서 “zip을 읽지 못함”으로 표시됩니다. (#330)

  7. 결과·다운로드 흐름 정리 2026-11-02
    • 변환 결과의 문제 보고 버튼 제거: 다운로드 버튼 옆의 문제 보고 버튼을 없앴습니다. 변환에 실패하면 진행 구역의 알림과 하단 문제 신고 안내는 그대로 남습니다. (#240)
    • 런처 CIA 설치를 다운로드 페이지로: 변환기는 게임 CIA와 런처용 파일(.neo3ds) 두 가지를 만들고, 런처 CIA 설치·업데이트는 다운로드 페이지에서 안내합니다. 예전 런처 모드 주소로 들어오면 다운로드 페이지로 이동합니다. (#242)
    • 변환기 화면 자잘한 정리: 팩 모드의 '런처가 없다면?' 안내를 변환하기 버튼 위로 옮기고, 빈 드롭 안내가 두 번 나오던 것을 고쳤습니다. (#244 #246)
  8. 로그에 바이오스 표시 2026-10-30

    게임마다 어떤 바이오스(AES/MVS)와 시스템으로 변환하는지 로그에 먼저 남깁니다. 게임 정보를 읽지 못해 실패해도 선택 상태를 확인할 수 있습니다. (#208)

  9. 모바일 화면과 배치 안내 2026-10-28
    • 배치 변환과 neogeo.zip 필수 안내: 드롭 영역 위에 변환 전 확인 상자를 두어 neogeo.zip(바이오스)이 모든 변환에 필요하고, 여러 게임을 한 번에 올릴 수 있고, MAME 롬셋 zip만 변환된다는 점을 먼저 보여 줍니다. 배치 변환이 실패하면 이유를 최대 3개까지 요약합니다. (#173)
    • 모바일에서 변환 페이지 제목이 먼저 보이게: 휴대폰 폭에서 제목이 드롭 패널 아래로 밀리던 순서를 고쳐, 화면을 열면 무엇을 하는 페이지인지 먼저 보입니다. (#174)
  10. 더 빠른 변환, 작은 파일 2026-10-26

    그래픽을 16KB 단위로 묶어 압축해 변환 시간이 줄고 파일도 조금 작아졌습니다. KOF '98 스프라이트 64MB가 22.2MB에서 20.3MB로 줄었습니다. 4KB 블록으로 만든 기존 CIA도 그대로 동작합니다. (#123)

  11. 진행 UI와 병렬 로그 2026-10-25
