다운로드와 설치

런처 CIA는 QR로 한 번만 설치하면 됩니다. 게임 파일은 변환기에서 만듭니다.

런처

업데이트는 런처만 하면 됩니다. 기존 .neo3ds 파일은 새 런처에서 그대로 돕니다. 게임별 CIA는 다시 변환해야 하고, 다른 버전의 퀵세이브는 불러올 수 없습니다.

게임 목록 앱입니다. 한 번 설치해 두면 .neo3ds 파일을 SD 카드에 넣고 목록에서 골라 실행합니다. HOME 아이콘은 하나만 생깁니다.

QR 코드로 설치

FBI → Remote Install → Scan QR Code.

최신 런처 CIA(약 450 KB)를 받습니다.

3DS는 인터넷에 연결되어 있어야 합니다(2.4 GHz Wi-Fi만 됩니다). PC와 같은 공유기일 필요는 없습니다.

SD 카드로 설치

QR이 안 되면 neo3ds-launcher.cia를 SD 카드에 넣고 FBI → SD → 파일 → Install CIA로 설치합니다.

SD 카드용 런처 CIA 파일 받기

게임별 설치

게임별 CIA를 쓰려면 .cia를 SD 카드에 넣고 FBI에서 설치합니다(SD → 파일 → Install CIA). 같은 게임은 CIA와 런처가 키 설정, 백업 RAM, 퀵세이브를 함께 씁니다.
