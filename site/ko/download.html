다운로드 & 설치

런처 CIA는 QR로 한 번 설치하고, 게임 파일은 변환기에서 만듭니다. 오프라인 변환기는 PC에서 실행합니다.

런처

업데이트는 런처만. 기존 .neo3ds 파일은 새 런처에서 그대로 돕니다. 게임별 CIA는 다시 변환해야 하고, 다른 버전의 퀵세이브는 불러올 수 없습니다.

게임 목록 앱. 한 번 설치하면 .neo3ds 파일을 SD 카드에 넣고 골라 실행합니다. HOME 아이콘은 하나만 생깁니다.

QR 코드로 설치

FBI → Remote Install → Scan QR Code.

최신 런처 CIA(약 400 KB)를 받습니다.

3DS가 인터넷(2.4 GHz Wi-Fi)에 연결되어 있어야 합니다.

PC와 같은 네트워크일 필요는 없습니다.

SD 카드로 설치

QR이 안 되면 neo3ds-launcher.cia를 SD 카드에 넣고 FBI → SD → 파일 → Install CIA로 설치합니다.

SD 카드용 런처 CIA 파일 받기

게임별 설치

게임별 CIA를 쓰려면 .cia를 SD 카드에 넣고 FBI에서 설치합니다(SD → 파일 → Install CIA). 같은 게임은 CIA와 런처가 키 설정·백업 RAM·퀵세이브를 함께 씁니다.

게임 CIA 만들기

오프라인 변환기

브라우저 없이 PC에서 변환합니다. .NET 런타임을 설치할 필요가 없고, 압축을 푼 폴더를 그대로 두면 됩니다.

Windows x64 받기 Linux x64 받기 macOS Apple Silicon 받기

macOS는 Apple Silicon 전용입니다. Intel Mac은 브라우저 변환기를 쓰세요.
