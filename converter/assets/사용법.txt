neo3ds 변환기 v{VERSION} — 압축을 풀면 이 파일이 있는 폴더 그대로 두세요.

1. 이 폴더(Neo3dsConverter.exe + tools 폴더)를 통째로 원하는 곳에 둡니다.
   exe만 따로 꺼내면 실행이 안 됩니다.
2. 게임 롬 zip과 neogeo.zip(바이오스)을 같은 폴더에 둡니다.
   zip 이름은 MAME 이름 그대로 (예: kof99.zip, neogeo.zip).
3. Neo3dsConverter.exe를 실행하고 롬 zip을 끌어다 놓은 뒤 [CIA 만들기].
   게임 하나에 1~2분쯤 걸립니다.
4. 나온 .cia를 SD 카드에 복사 → 3DS의 FBI → Install CIA.

처음 실행 때 Windows가 "알 수 없는 게시자" 경고를 띄우면 [추가 정보] → [실행].
소리가 안 나면 SD 카드에 /3ds/dspfirm.cdc 필요 (준비물: README 참고).
